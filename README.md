# Simon Memory Challenge

A responsive Simon Memory Challenge game built with HTML, CSS, and JavaScript. Test your memory by repeating an increasingly complex sequence of colors.

 # Features
 
- Interactive gameplay
- Smooth button animations
- Sound effects
- Score/Level progression
- Responsive design
- Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
.
├── index.html
├── style.css
├── main.js
└── sounds/
    ├── blue.mp3
    ├── green.mp3
    ├── red.mp3
    ├── yellow.mp3
    └── wrong.mp3

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/Shivam70074/simon-memory-challenge.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
